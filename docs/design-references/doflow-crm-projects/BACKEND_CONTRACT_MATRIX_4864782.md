## Migration decision

One additive release migration will carry independent, explicitly typed domain tables/columns for the **E** portions above. It will not modify migration 185, will not contain `DROP`/`TRUNCATE`, will validate every tenant schema through `safeSchema`, and will not be executed against production in this task. Contracts classified B/C/D without missing storage reuse their current authoritative persistence.

Google Calendar OAuth remains provider-disabled unless its required server configuration exists. LiveKit remains disabled. Neither limitation blocks the management workflows that can be completed safely without those external providers.
